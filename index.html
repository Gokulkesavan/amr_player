Reads SIP/SDP to learn the AMR mode, correlates RTP streams, and writes proper .amr / .awb files — with lost frames padded as NO_DATA so the duration stays correct. WAV conversion runs entirely in your browser via an embedded opencore-amr WASM decoder — no server, no SharedArrayBuffer, works on static hosting.
